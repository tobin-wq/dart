# Dart
Dart is a little menu on the left side of your screen. There is a little bar that when hovered over opens the menu with every app that's open. To download the app, go to [dart.dmg](https://github.com/tobin-wq/dart/blob/main/dart.dmg) either in main or from the link, and click on View raw

Dart was inspired by Richard Qi's [TabTab](https://tabtabapp.net/) app.
